## 取舍（已和用户确认）

1. **请求来源**：检查器只记录接口类型（openai / claude…），不记是哪个插件发的。→ 按消息内容和时间推测（主回复 / 记忆图 / 编排某个助手 / 迭代），推测不出的标「其他」，界面注明是推测。
2. **编排运行记录**：API 没有历史、没有超时 / 重试字段，只有当前一次运行。→ 工作台自己订阅 `run-state/store.js` 记下每次运行。小建议改成「某个助手经常出错」「某个助手占了一半以上用时」，去掉「超时 N 次」。
3. **「立刻合并」**：记忆图的手动压缩没有公开接口。→ 去掉这个按钮。保留改设置类的一键操作（常驻回溯楼层、打开自动合并）。
4. **群聊**：几乎没人用。→ 群聊当作「未选择角色卡」处理，记忆图 / 编排 / 预设照常用全局。

## 要在样稿里跟着改的地方

- 待处理里「立刻合并」按钮 → 换成「打开自动合并」或去掉
- 编排的小建议文案「最近 5 次有 2 次超时」→「最近 5 次有 2 次出错」
- 问问的耗时表加一句「来源是根据内容推测的」
