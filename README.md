# 工作台（Luker Workbench）

Luker 的第三方扩展：一个可拖动的浮动窗口，把记忆图、编排、预设、角色卡四个 AI 工作台放在一起。

- **总览**：提示词各部分占多少 token；小建议（本地规则检查，不花 token）；四个工作台的状态。
- **问问**：只读助手，会自己去看请求检查器、日志、聊天、角色卡、世界书、预设、记忆图和编排，回答「为什么慢」「为什么报错」「为什么她忘了」这类问题。
- **AI 迭代**：用平常的话告诉 AI 想改什么，AI 给出逐条的改动清单，勾选后再应用。分全局 / 当前角色卡。
- **改动记录**：应用过的改动都能单独撤销。

## 安装

Luker →「扩展」→「安装扩展」，粘贴：

```
https://github.com/xzhouzhou758/luker-workbench
```

装好后从魔杖菜单打开「工作台」，或按 Alt+W。

## 说明

- AI 用的连接配置和生成预设在「设置」里选，工作台只是选用，不会改你的预设。
- 改动先给你看，确认后才写入 Luker。
- 配合 [记忆透镜](https://github.com/xzhouzhou758/memory-lens)、[编排透镜](https://github.com/xzhouzhou758/orchestra-lens) 使用更方便，不装也能用。
